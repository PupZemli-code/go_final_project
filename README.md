# Файлы для итогового задания

В директории `tests` находятся тесты для проверки API, которое должно быть реализовано в веб-сервере.

Директория `web` содержит файлы фронтенда.

Директория `internal\server` содержет код для создания сервера.

Директория `pkg` содержит 3 пакета необходимые для работы:

- `api` содержит бизнес логику проекта
- `db` содержет код для создания базы данных, обработки запросов к ней, 
    а так же является путем по умолчанию для хранения базы данных.
- `logger` содержит настройки логера.

Релизованы все задания со зведздочкой, кроме Docker.

При помощи переменных окружения можно настроить следующие параметры запуска:

- `TODO_PORT`= устанавливает порт на котором будет запущено приложение.
- `TODO_DBFILE`= устанавливает путь к базе данных.
- `TODO_PASSWORD`= устанавливает пароль для приложения.
